# Repository instructions

Read and follow `REASONIX.md` before changing this repository. The mandatory
fork workflow is documented in `docs/FORK_MAINTENANCE.md` and
`docs/FORK_MAINTENANCE.zh-CN.md`.

Start all work from `custom/baize` on a short-lived `feat/*` or `fix/*` branch.
`main-v2` is a read-only, fast-forward-only mirror of `upstream/main-v2`.
